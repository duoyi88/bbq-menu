# 菜單圖片 Gemini Nano Banana Prompt 清單

> 使用方式：透過 OpenCode 的 mcp-image MCP Server 直接生成，或手動貼到 Gemini。
> 圖片規格：1:1 比例, webp 格式
> 攝影風格統一：**台灣燒肉店菜單風格** — 乾淨明亮的人工光源、深色圓盤或方盤、正上方或 45 度角、背景簡潔深色、重點呈現食材本身。
> 所有食材皆以**原始未烤狀態**呈現，標註實際規格與台灣市售型態。

---

## 全域風格指令（每個 prompt 尾端已內建，無需額外前綴）

```
Style: Clean Japanese yakiniku restaurant menu photography. Bright even studio lighting from above, dark matte round or rectangular plate, dark solid background. Focus on the food item itself. No garnish unless specified. No text, no watermark, photorealistic. Ratio 1:1
```

## 使用步驟

### 方式一：OpenCode MCP（推薦）

1. 在 OpenCode 對話中直接說：「用 mcp-image 生成 [品項名稱]，1:1 比例」
2. 或貼入上方完整 Prompt
3. 生成後轉檔為 `.webp`（可用 squoosh.app）
4. 存放到 `public/images/items/` 或 `public/images/sets/` 對應檔名

### 方式二：手動使用 Gemini

1. 開啟 Gemini（選擇 Nano Banana 或 Flash Image 模型）
2. 直接貼入完整 Prompt
3. 產圖後下載，轉檔為 `.webp`
4. 存放到對應路徑

### 套餐組合圖建議流程

1. 先生成所有需要的**單品圖**（上方 items 區域）
2. 使用 Figma / Canva / Photoshop 將單品圖拼合到深色背景上
3. 手動調整大小和位置，模擬俯拍擺盤效果
4. 這樣每個食材都會精確正確，不會出現 AI 一次性生成的錯誤
